# Generate Stock & Crypto Charts Using Artifacts

### Overview

The Artifact transforms AI responses into rich, interactive visual outputs instead of plain text.&#x20;

In Graice, Artifacts automatically generate professional charts, graphs, dashboards, and data visualizations from natural language prompts.

Instead of receiving only a text response, users can interact with visual dashboards to analyze trends, compare market data, explore technical indicators, and gain actionable insights all within the same conversation.

{% hint style="info" %}
Artifacts are generated automatically whenever the selected AI model supports artifact generation and the prompt requires a visual or interactive response.
{% endhint %}

## Generate a Stock Market Artifact

Follow the steps below to generate an interactive investment report and Stock Market dashboard.

***

### Step 1 — Create a New Chat Thread

Create a new chat thread from the Graice Chat interface.

Next, select **Claude Opus 4.8** (or any other supported high-end AI model) from the model selector.

After selecting the model, enter your Stock Market prompt in the chat input box.

Use the following prompt:

```
Analyze NVIDIA (NVDA) and create a professional investment report with live price, financials, technical analysis, charts, risks, opportunities, and a Buy/Hold/Sell recommendation.
```

After entering the prompt, click the **Send** icon.

### Step 2 — Select the Correct Stock Listing

After submitting the prompt, Graice may ask you to confirm the exact financial instrument.

This happens because multiple companies or financial products may have similar names.

Review the available results carefully and select the correct company from the list.

For this example, select:

**NVIDIA Corporation (NASDAQ: NVDA)**

Once selected, Graice automatically continues generating the investment report.
